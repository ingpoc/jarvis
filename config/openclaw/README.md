# OpenClaw Config Snapshot

This folder tracks a redacted snapshot of local OpenClaw runtime config for change history.

Files:
- `openclaw.redacted.json`: redacted from `~/.openclaw/openclaw.json`
- `auth-profiles.redacted.json`: redacted from `~/.openclaw/agents/main/agent/auth-profiles.json`

Secrets are replaced with `***REDACTED***`.
