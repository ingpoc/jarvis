## Context

X links can show login walls or partial content, causing silent or low-quality analysis if fallback is not explicit.

## Memory

Use extraction cascade:

1. browser snapshot on original URL
2. open in-post Article/Focus link when available
3. follow outbound primary sources
4. mirror fallback only when blocked

Only score with full evidence or primary-source coverage.

## Retrieval Cues

- x.com link shared
- social post appears partially blocked
- article quality uncertain without outbound links
